# AI-Cyberattack-Network-Intrusion-Detector
A Machine Learning-based AI Cyberattack &amp; Network Intrusion Detector using the RT-IoT2022 dataset to classify network traffic and detect cyberattacks. The project compares Logistic Regression, KNN, Decision Tree, Random Forest, and Naive Bayes using Accuracy, Precision,Recall, and F1-score, with Random Forest achieving the best overall performance.
